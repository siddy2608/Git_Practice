# Client Portal — Architecture Roadmap

## Overview
This folder is reserved for the future **Client Acceptance & Milestone Review Portal**.

## Sprint 1 Status
Per the Sprint 1 strict scope specifications:
- The Client Portal is **not developed** in Sprint 1.
- Only the **Admin Main Dashboard**, **Login Page**, and **Registration Page** are active.
- Self-registered users provisioned via `register.html` receive a non-privileged `Company User (Pending Approval)` status and cannot enter the Admin Main Dashboard.

## Planned Sprint 2 Architecture
When implemented:
1. Client users will access a dedicated, branded external view (`client/index.html`).
2. Capabilities will include:
   - Reviewing delivered milestone deliverables and technical verification proofs.
   - Formal sign-off and issuance of digital acceptance certificates.
   - Logging structured milestone exception disputes.
   - Viewing issued invoices and payment remittance receipts.
