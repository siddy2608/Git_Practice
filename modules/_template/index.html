Theme-Compliant Component Quickstart

When building new modules in modules/<module-id>/, adhere strictly to the following patterns:

  • Zero Hardcoded Hex: Use CSS variables exclusively (e.g., var(--color-primary-600), var(--bg-surface), var(--border-color)).
  • Numbers & Currency: Always use tabular-nums formatting via font-variant-numeric: tabular-nums; and format with Indian numbering (Lakhs / Crores).
  • Cards: Use .card, .card-header, .card-title, .card-body, and .card-footer.
  • KPI Metrics: Use .kpi-grid and .kpi-card with .kpi-label, .kpi-value, and .kpi-trend.
  • Badges: Use .status-badge with states .status-ready, .status-in-review, .status-awaiting-sign-off, .status-at-risk, .status-client-accepted, or .badge-success, .badge-warning, .badge-danger, .badge-info.
  • Buttons: Use .btn with .btn-primary, .btn-secondary, .btn-outline, .btn-ghost, .btn-danger.
